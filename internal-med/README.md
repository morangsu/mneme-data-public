# 中医内科学（internal-med）

**四级链压力测试**：病 → 证 → 治法 → 方。

## 文件

| 文件 | 说明 |
|---|---|
| `domain.toml` | 学科 schema（13 字段 / 3 出题方向） |
| `manifest.json` | 文件级 sha256 |
| `data/*.csv` | 基础条目数据 |

## 两级 relations

| 关系 | 表达 | 例子 |
|---|---|---|
| `patterns`（带 `order`） | 病 → 下属证型 | 感冒 → 风寒束表(1) / 风热犯表(2) / 暑湿伤表(3) |
| `prescriptions`（带 `role`） | 证型 → 治法 → 代表方 | 风寒束表 → 辛温解表 → 荆防败毒散 |

`role` 复用为「治法」，是「方随证转」的关键。

## 实测

3 个真实病证产出 33 张卡：主症推病、证型推方、背证治方链、类证鉴别。
`pattern:风热犯肺` 反查正确命中「咳嗽」。
