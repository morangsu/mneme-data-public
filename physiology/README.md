# 生理学（physiology）

过程导向学科：**步骤顺序本身就是知识**。适用于生理过程、生化代谢通路、诊疗路径。

## 文件

| 文件 | 说明 |
|---|---|
| `domain.toml` | 学科 schema（`process` 实体 + 有序 `steps` 关系 + 排序/挖空方向） |
| `manifest.json` | 文件级 sha256 清单 |
| `data/*.csv` | 基础条目数据 |

## 特殊设计

1. **有序步骤**：`[[entities.relations]]` 的 `order` 字段标明步骤序号（1 起）。
   CSV 里写 `葡萄糖::::1|葡萄糖-6-磷酸::::2`（第 5 段是 order，前 4 段 role/amount/note 留空）。
2. **排序题**：方向声明 `sequence = true` → 生成「排出正确顺序」卡，
   题面确定性乱序（保证每次同样，且一定不同于正确答案）。
3. **挖空题**：方向声明 `cloze = true` → 把概述挖空让人填空。

## 已知不足

- 复杂通路（如糖酵解十步）当前以线性 `order` 表达，尚不支持分支/循环。
  需要时再扩展 `Relation` 的 `branch` 语义。
