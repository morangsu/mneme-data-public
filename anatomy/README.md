# 解剖学（anatomy）

结构导向学科：**位置、毗邻、图示指认**是核心考点。

## 文件

| 文件 | 说明 |
|---|---|
| `domain.toml` | 学科 schema（`structure` 实体 + `image` 字段 + `image_marks` 标注） |
| `manifest.json` | 文件级 sha256 清单 |
| `data/*.csv` | 基础条目数据 |
| `images/` | 解剖图（相对路径由数据的 `atlas` 字段引用） |

## 特殊设计

1. **图片字段**：`kind = "image"`，值存**相对数据目录**的路径（`anatomy/heart.png`）。
2. **标注坐标**：CSV 的 `marks` 列，格式 `标签:x:y:w:h|标签2:x:y`，
   坐标为 **0..1 相对比例**（换分辨率/缩放不失效）；越界坐标导入时自动丢弃。
3. **图示定位题**：方向声明 `image_locate = true` + `image_field = "atlas"`，
   生成「在图中指出『左心室』的位置」，答案带比例坐标供前端高亮。

## 数据格式示例

```
心脏,structure,循环系统,false,1,左心室:0.62:0.55:0.12:0.22|右心室:0.38:0.55:0.12:0.22,...,anatomy/heart.png,...
```

## 方位关系（P2-8）

`spatial = true` 后可用 `spatial` 列表达「A 相对 B 的方位」：

```
spatial = 肺:内|纵隔:内|膈:上|胸骨:后
          └目标┘└方位┘
```

**受控方位词**：上/下/左/右/内/外/前/后/浅/深/周围（非法方位导入时自动丢弃）。
方向声明 `spatial_clue = true` 生成「心脏 位于 肺 的哪个方位？→ 内」。

`SpatialRelation::opposite()` 提供方位对调（上⇄下、内⇄外），供反向推理用。

## 已知不足

- 目前只支持矩形与点两种标注，不支持多边形/曲线。
- 图片本身需自行放入 `images/`（或用 `data/` 下的相对路径），仓库不内置图库。
