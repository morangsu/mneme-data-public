# 中医诊断学（diagnostics）

症状群 → 证型。**同症异证**是核心难点：「乏力」同时见于脾气虚、脾阳虚、心气虚。

## 文件

| 文件 | 说明 |
|---|---|
| `domain.toml` | 学科 schema（12 字段 / 2 出题方向） |
| `manifest.json` | 文件级 sha256 |
| `data/*.csv` | 基础条目数据 |

## 用到的 schema 能力

| 能力 | 用途 |
|---|---|
| `scope = "category"` | 多证同症时先按虚/实限定 |
| `enumerate_if_ambiguous` | 眼目不唯一时列举并说差异 |
| `differential` | 类证鉴别（脾气虚 vs 脾阳虚：有寒象） |
| `immutable` | 舌象、脉象不可改 |
| `cloze = true` | 挖空主症列表 |

## 实测题型

5 个证型产出 48 张卡：症状群推证型（34 张，含歧义枚举）、
背主症（挖空）、类证辨析（4 张）。

## 已知不足

辨析题的候选来自「共享症状」的全库反查，未限定同 `category`，
可能把「心气虚」列进「脾气虚」的辨析对象（两者共享「乏力」但非最相近类证）。
后续可把 `scope` 用于辨析候选过滤。
