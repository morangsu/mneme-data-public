# 伤寒论（shanghan）

条文 → 方证对应。核心是「**方证对应**」：给症状推方、给方推条文。

## 文件

| 文件 | 说明 |
|---|---|
| `domain.toml` | 学科 schema（13 字段 / 3 出题方向） |
| `manifest.json` | 文件级 sha256 |
| `data/*.csv` | 基础条目数据 |

## 用到的 schema 能力

| 能力 | 用途 |
|---|---|
| `group_kind = "chapter"` | 按篇次分组 |
| `[[entities.relations]]` | 条文 → 主方（桂枝汤/麻黄汤） |
| `cloze = true` | 挖空原文背条文 |
| `differential` | 类证鉴别（中风 vs 伤寒：有汗无汗） |
| `immutable` | 原文、条文号不可改 |
| `enumerate_if_ambiguous` | 眼目不唯一时列举并说差异 |

## 实测题型

同一批 3 条条文产出 26 张卡：条文推方证、眼目推方（14 张）、
背条文（挖空）、类证鉴别。

## 数据格式示例

```
太阳中风条文2,article,辨太阳病脉证并治,false,1,桂枝汤::::2,条文2,太阳病发热汗出恶风脉缓者名为中风,...
                                                    └主方关系（order=2）
```
